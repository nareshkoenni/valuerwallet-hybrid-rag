# Data availability

The study uses the operational ValuerWallet valuation database and a corpus of scanned property
documents. They contain customer contact details, staff e-mail addresses, property coordinates and
building names, and they are proprietary. They are therefore **not** distributed, and neither is
anything from which they could be reconstructed (the file-level corpus, the embedding matrix, the
candidate pools, or ranking files that list real file numbers).

## Released here

* All code needed to rebuild the corpus, the benchmark, the index and the evaluation (`vwrag/`).
* The benchmark specification and question templates (`benchmark/`).
* Aggregate metric tables and manifests (`results/paper2/`).
* `results/paper2/per_query_ranks_v2.csv`: for each of the 20,340 queries, the 1-based rank of the
  target under each system. It contains no identifiers, text or file numbers.

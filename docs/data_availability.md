# Data availability

The underlying ValuerWallet database and physical valuation-document corpus are proprietary operational data and are not released in this repository.

Private materials may contain client and property information, valuation file identifiers, document metadata, photographs, legal records, utility documents, and other confidential content. They must not be uploaded publicly.

Only code reviewed for confidentiality and artifacts checked for identifiers may be released. Any public benchmark or example data should use synthetic or appropriately anonymized records and must not permit re-identification.

This repository does not contain the database, physical documents, embeddings, private mappings, raw evaluation outputs, or a complete validated reproduction pipeline.
